## Narrative

An incident changes while an agent is deciding. Blackout makes the decision-to-execution gap visible: review finite alternatives, retain the response, then check the exact evidence and human confirmation again before applying any local lab action.

1:35–2:02: measured process rig, if complete: actual queued/completed counters, worker-stop injection, fresh bounded recovery and child cleanup. Explicitly distinguish measured process telemetry from model ticks. This sequence must be understandable without dropping context.
